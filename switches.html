How effective is the stagger?

Where I’d call it. Run it after the first Cluj action stalls and there is time for 3 to cross the floor. Against a chasing defender, 3 can shoot or turn a hard closeout into a paint touch. A downhill 1 on the empty side gives the defense another threat if 3 is covered.

The shot and the pass. The original wing spot was about 32 feet from the rim. 3 now turns back toward the arc for a catch about 24 feet out. Only take it if that is a practiced shot. The pass is still about 36 feet. If a defender gets a hand in that diagonal, 1 keeps the ball and uses 4.

Where it breaks down. A clean switch at the second screen can put X2 on 3 before the catch. If X3 denies the high exit, a backcut needs a clear rim and passing lane. 1 waits for that cut to clear before rejecting. If 5 cannot draw X5 out, expect help at the rim. A square closeout with X5 inside favors moving it to 4.

Test it in practice. Alternate this set and your usual second action with the same lineups and starting clock. Have the defense chase, switch or deny the exit. For every call, log coverage, whether 3 caught in range, the first clean look (uncontested shot in range, rim attempt or shooting foul), turnovers and total points through the end of the possession. Compare clean looks per call and points per possession by coverage, including denied catches. Record the number of calls in each group.
